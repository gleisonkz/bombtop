# Thor and Captain sprite-family shield

User requested closer adherence to actual Thor/Captain assets after liking the stronger construct concept. Built-in image_gen used previous shield only for design, extracted actual captain.png/thor.png pixels for line/shading style, and energy-effects-pixel.png for VFX detail. Exact prompt saved in prompt.txt. New16distinctframes exported by pack.py, fine160pxlogicalcell, shared16colorpalette, binaryalpha, native320cells. Protection/open/release timing unchanged. Nearest texture filtering and normal RGBA blend preserve dark sprite contours instead of bleaching them with additive blending.

Production lantern-construct-shield.png, versionedURL thor-cap-3. Source and targeted5173checkout both updated. lantern-preview.gif is a composed demonstration using the existing unchanged Lantern sprite. Prior versions remain archived in sibling concept folders.
