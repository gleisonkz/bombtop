# Pixel art Goku aura

User-requested pixel-art replacement for the painted aura. Built-in image_gen used the approved aura pixels and ability-effects-pixel.png as references. Original tool output: source.raw.png. A single uniform nearest-neighbor board resize to1004px precedes frame registration by pack.py; pixel-export.py samples every registered320px cell to logical80px, quantizes to five gold colors with binary alpha, and exports4x nearest-neighbor. Sixteen distinct drawings. Character remains separate. Updated descriptor keeps previous intro/loop/release and20fps contract; menu/victory only.

Production goku-ssj-aura-pixel.png and goku-ssj-aura.json. Original painted public atlas preserved. Layering fix lives in ui/goku-aura-preview.ts and localized cast CSS. No gameplay aura.
