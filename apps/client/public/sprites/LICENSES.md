# Sprite licenses

Trial character sheets. Both are CC0 (public domain, no attribution required).

- `foozle-legend.png` — "Legend - Main Character" by Foozle (commissioned from Atari Boy),
  https://foozlecc.itch.io/legend-main-character — CC0 1.0
- `james.png` — "Pixel Character 02 - James", https://opengameart.org/content/pixel-character-02-james — CC0 1.0
- `ninja.png` — the project's own character, made in PixelLab (pixellab.ai) for Bombtop;
  rows: idle S/E/N, walk S/E/N (6 frames), hit (6), death (7), ice-blast cast S/E/N (9); 64px cells.

## bombs.png

Own art for this project. Normal and spiked (pierce) bombs generated in PixelLab;
the remote bomb is the normal one with its fuse hand-replaced by an antenna.
Cells (32x32, left to right): normal, pierce, remote.

## flames.png

Own art for this project, generated by a script (procedural pixel art, no source images).
Rows (32x32 cells): fireball center, arm segment, arm tip; columns: 5 stages of a flame's life.

## items.png

Own art for this project, generated by `scripts/build-items.py` (plates and icons drawn in code;
bomb, pierce and remote items reuse bombs.png). Columns (48x48): one per item, order = `ITEMS.order`
in `src/render/sprites.ts`; rows: plain, then 3 frames of a glint.

## tiles.png

Own art for this project, generated by `scripts/build-tiles.py` (procedural pixel art, no source images).
Cells (32x32, left to right): grass A (plain, flowers, pebbles), grass B (same, darker), breakable block,
inner pillar, border wall. Order = `TILES.cells` in `src/render/sprites.ts`.
